Read: Llama leads downstream (47.4 avg3) and throughput (~675 KB/s vs byte ~495–509) — subword packs 4.541 B/tok, so it clears more text per step, though at a different (non-iso-FLOP) compute-per-byte axis. Among byte models rg ≈ AU-Net ≈ ByteFlow; BLT is ~2× slower (entropy model in the loop). ByteFlow global-top-k is weakest on both BPB and downstream.

This is the partial-token problem measured as a benchmark (Athiwaratkun et al. 2024, Token Alignment via Character Matching; Xu et al. 2026, A Practical Study of the Partial Token Problem, arXiv:2601.23223). Committing the boundary space into the prompt makes it end mid-token for the subword vocabulary — off-distribution — so the scored continuation is distorted. ΔAcc = space − canonical over the full test sets (ARC-E 2376, HS 10042, ARC-C 1172; avg = macro-mean). Byte models see identical bytes either way, so every option shifts by the same constant and Δ≡0 by construction. ARC-Easy shows the largest effect (short answers → the boundary token dominates the choice's total logprob); HellaSwag the smallest (long continuations dilute it). No fix (token healing / alignment) is applied — this is the benchmark measurement only.

6. Examples — what each eval / benchmark looks like

One worked item per eval so the tables above are legible. Synthetic probes (§4c–d, §5) are real generator output; MCQ items (§1–3) are representative. Green = gold answer / predicted target. Scoring is length-normalized or raw loglikelihood: build (context, continuation) per option and pick the max.

Downstream MCQ (§1–3)

HellaSwag — commonsense sentence completion, 4 endings (acc_norm)

Ctx: A woman is outside with a bucket and a dog. The dog keeps running around to avoid a bath. She a) rinses the bucket and blow-dries the dog's head. b) uses a hose to keep the dog from getting soapy. c) gets the dog wet, and it runs away from her again. d) climbs into the bucket with the dog. scored: Ctx + "\nAnswer:" -> continuation " <ending>", argmax normalized logprob

ARC-Easy / ARC-Challenge — grade-school science MCQ, 4 choices (acc_norm); ARC-C = the hard split

Q: Which is the best source of light for a plant to grow? a) the moon b) a mirror c) the sun d) a candle

PIQA — physical commonsense, 2 solutions (acc_norm)

Goal: To separate an egg yolk from the white. sol1: Squeeze an empty water bottle over the yolk to suck it up. sol2: Pour the whole egg through a fork to catch the yolk.

BoolQ — yes/no reading comprehension (acc)

Passage: A windmill uses vanes called sails to convert wind into rotational energy, which can drive a generator... Question: can a windmill generate electricity? -> yes / no

WinoGrande — pronoun/blank resolution, 2 fills (INVERSE scoring: per-option context, shared suffix) (acc)

The trophy did not fit in the suitcase because the _ was too large. option1: trophy option2: suitcase scored: two blank-filled contexts + one shared continuation; pick the likelier context

MMLU-text — 57-subject knowledge MCQ, 4 choices (acc)

Q (astronomy): A light-year is a unit of ____. a) time b) distance c) brightness d) mass

Bits-per-byte (§1–2)

BPB — held-out next-byte prediction, bits/byte (↓)

"...the sun is yellow. Here we go..." -> model gives P(next byte | prefix); BPB = mean(-log2 P) Llama's per-token NLL is converted x4.548 bytes/token so all families share one byte axis.

Robustness — input perturbation (§4)

PBP-mc — shift ONE boundary space at the prompt cut (§4a)

canonical: "...she opened the| door" (cut BEFORE the space) shifted : "...she opened the |door" (space moved across the cut) byte models: same bytes -> ~0 delta; Llama re-tokenizes the tail -> acc drops (ARC-E -21.5)

Noise / Typo — char-level corruption of HS / ARC-C (§4b)

clean: "The chef seasoned the soup" typo: "The chef sesaoned the suop" (swap / drop / dup ops)

Despace — remove each intra-line space w/ prob p; ctx = context only, all = + answer (§4c–d)

clean : "Question: The child wanted to play so she\nAnswer:" + opt " ran outside to the yard" ctx40 : "Question:The child wantedto play so she\nAnswer:" (context spaces dropped @40%) all40 : ctx as above + opt " ran outside totheyard" (answer despaced too) ctx100: "Question:Thechildwantedtoplaysoshe\nAnswer:" (every space gone)

State tracking & recall (§5) — teacher-forced greedy: predict the next token

FFLM — flip-flop register; w=write, i=ignore, r=read. After each r, predict the most-recent written bit.

w 0 w 1 r 1 r 1 r 1 w 0 r 0 r 0 w 1 r 1 ... (the read after "w 1" must output 1, after "w 0" must output 0 — hold the last write across i-distractors)

Dyck-3 — balanced brackets; at a close, predict the bracket matching the most-recent unmatched open.
