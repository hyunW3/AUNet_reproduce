# Misleading context — 방향 설계 (2026-10-04)

## 왜 방향을 바꾸나

- "선택지를 질문 앞에 나열 + 텍스트 이어쓰기 채점"(echo_all)은 실제로 쓰는 프롬프트 형식이 아니다. 진단용으로는
  유용했지만 그대로 논문의 약점 주장으로 쓰기는 어렵다.
- 자연스러운 표준 MCQ(선택지를 질문 뒤에 두고 알파벳으로 답)는 1B base 모델 다섯 개 모두 chance라 비교 근거가 없다
  (`POSITION_SUMMARY.md`).
- 지금까지의 데이터가 가리키는 현상은 **"BLT는 문맥에 나온 답 후보 문자열에 더 강하게 기댄다(context reliance)"**이다.
  무관한 문장(A 그룹)에는 아무 모델도 흔들리지 않았고, 오답이 정보로 제시될 때(B 그룹)와 목록으로 제시될 때만 BLT가
  더 끌렸다. 반대로 문맥을 따라야 하는 과제(NIAH, NoLiMa)에서는 BLT가 가장 강했다.

→ **"context reliance"를 양면으로 재는 프레임**을 제안한다. 문맥을 따라야 할 때의 이득과, 따르면 안 될 때의 손해를
같은 문항에서 같이 잰다. 이렇게 하면 "BLT가 약하다"가 아니라 "BLT는 문맥 의존도가 높다 — 신뢰할 수 없는 문맥에서는
손해"라는 정확하고 방어 가능한 주장이 된다.

## 자연스러운 설정 후보 (모두 cloze 채점, 1B base에서 측정 가능)

| # | 설정 | 실제 사용 맥락 | 문맥을 따라야 하나 | 구성 |
|---|---|---|---|---|
| M1 | **사용자 제안 답 (sycophancy)** | 채팅에서 사용자가 자기 생각을 먼저 말함 (Sharma et al. 2023 형식) | 아니오 | "I think the answer is ⟨X⟩, but I'm not sure." + 질문. X = 오답 / 정답 / 무관 |
| M2 | **출처 신뢰도가 다른 검색 문서 (RAG 충돌)** | 검색 문서에 틀린 정보가 섞임 | 신뢰도에 따라 | "According to ⟨a textbook / an online forum / a joke website⟩, …⟨X⟩." 출처별로 끌림이 달라지는가 = 신뢰도 구분 능력 |
| M3 | **어휘만 겹치는 무관 문서** | 검색이 키워드만 맞는 문서를 가져옴 | 아니오 | DCLM에서 오답 선택지 단어를 포함한 실제 문장 1–3개(질문과는 무관) vs 정답 단어 포함 문장 vs 무작위 문장 |
| M4 | **문맥 충실성 (counterfactual)** | 독해 / RAG에서 문서가 정답의 근거 | **예** | "In this passage, … ⟨X⟩." → "According to the passage, …?" 문맥의 X를 고르면 정답(NQ-Swap 류). 이득 측 지표 |
| M5 | **few-shot 시연의 라벨 편향** | 가장 흔한 실제 프롬프트 방식 | 아니오 | Zhao et al. 2021의 majority-label / recency bias: 시연 라벨을 한쪽으로 몰거나 마지막 시연 라벨을 바꿔 편향 측정. 시연 라벨을 틀리게(flipped) 줄 때의 추종도(Min et al. 2022) |

- M1, M2, M3은 "따르면 안 되는 문맥", M4는 "따라야 하는 문맥", M5는 실제 few-shot 사용에서의 위치·라벨 편향
  (echo_all의 첫 선택지 편향이 실제 설정에서 나타나는 형태)이다.
- 이미 측정한 B 그룹(soft / student / neg)은 M1·M2의 축소판이다. neg_gold에서 모든 모델이 부정을 무시한 결과도
  M2의 "신뢰도 구분" 질문과 연결된다.

## 판정 지표

- **취약도** = 따르면 안 되는 문맥에서의 정확도 하락(M1, M2-저신뢰, M3)
- **충실도** = 따라야 하는 문맥에서 문맥을 따르는 비율(M4)
- **구분도** = 고신뢰 출처 추종률 − 저신뢰 출처 추종률(M2)
- 모델별로 (충실도, 취약도)를 2D로 찍는다. matched trio에서 tokenizer 효과를 보고, BLT / H-Net은 외부 reference로 둔다.
  외부 subword 대조군(Llama-3.2-1B, Qwen2.5-1.5B, OLMo-1B)을 넣으면 "대규모 학습 vs byte 구조"도 가를 수 있다.

## 우선순위 제안

1. **M5 few-shot 라벨 편향**: 가장 자연스럽고 널리 쓰이는 설정이며 기존 문헌과 바로 비교된다.
2. **M1 사용자 제안 + M4 충실성 쌍**: 같은 문항으로 양면을 함께 측정할 수 있다.
3. M3 어휘 겹침 문서: 자연 텍스트 기반이라 리뷰어 설득력이 높다.
4. M2 출처 신뢰도: 1B base가 신뢰도를 구분할지는 불확실하지만 결과가 나오면 흥미롭다.
