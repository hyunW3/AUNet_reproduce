BPEByte hybrid — dashboard all BPEByte variants

All BPEByte variants in one view: the rg control (pure root_greedy, rg dashboard) vs the hybrid prefill/decode family. Hybrid = an offline/online prefill region (leak-tolerant, non-causal) followed by a root_greedy decode region (0-leak, causal) — the decode part stays byte-reproducible while the prefill part gets BPE-like compression.

Placement
leaf = before_root, offline real-BPE · bt = before_root, online backtracking/longest-match · root = offline-BPE at root placement. Decode is always root_greedy.
Boundary (prefill fraction of doc length N)
(0,N)=full · N/2=static-half · (N/3,2N/3)=mid.
Notation {placement}-{mode}
root-online-gr (=greedyQ) · leaf-offline (=leafQ) · root-offline (=rootQ) · leaf-online-bt (=btQ). MC scores the answer greedily, so question tokenization matters only via placement → the three before_root modes are byte-identical; only root-offline differs. This collapse holds at every scale/recipe.
BPB split
Decode@0.5 = leak-free, primary · Full@0.5 = leak-contaminated diagnostic.

What the ablation says

  1. Hybrid prefill beats the rg control on downstream by ~+5 pts at 100M (leaf/bt 44.6–45.6 vs rg 40.5) and collapses Full-BPB 1.79 → ~1.13. The gain scales: all three 300M configs jump ~+7 pts (100M→300M) to 51–53.
  2. Placement is the only axis that moves anything. leaf ≈ bt everywhere (offline real-BPE ≈ online backtracking); boundary rule is second-order. root prefill lands with the control on downstream (~40) despite the lowest leak-free Decode-BPB.
  3. Decode-BPB ⊥ downstream (a warning). On the law recipe, root prefill wins Decode-BPB but loses downstream; the leaf/bt winners carry the highest Decode-BPB. Full-BPB tracks downstream correctly (leaf/bt ~1.13 < root ~1.17 < control 1.79). Don't rank hybrids by leak-free decode BPB alone.
  4. At 300M the config choice is statistically tied (limit=1000, 3-bench CIs ±1.7–1.8 overlap): leaf·N/2 52.8, leaf·MID 52.7, bt·N/2 51.3, Decode-BPB all ~0.99. Only the +7 pt scale gain is robust; separating leaf-vs-bt / N/2-vs-MID needs full test sets or seeds, not more training.
Recipe note. Two recipes at the same γ10.4 token budget: AU-Net-law (batch 48, 53,504 steps @100M — the numbers here) and ad-hoc (batch 768, 3,344 steps). Law runs ~0.05–0.10 BPB / +3–4 downstream pts better; the ad-hoc 10-cell matrix (same relative ordering, worse absolutes) is the bottom half of leaderboard_100M_hybrid_matrix.md.
